# 样章与技法锚点

以下为已交付并获认可的四份样章。作用是对齐质量标准，不是供直接复制的模板——复用句式前应替换全部具体物件。

---

## 一、《半根冰棍》（怀旧民谣，4 分钟）

**钩子**：无口号式副歌，靠具体物件堆出回忆，末句"我闭上眼睛就能听见整个夏天"收尾。

**关键技法**

- 主歌纯粹白描，前八句里出现七个实物（蝉、槐树、两毛钱、冰棍箱、自行车、沙包、玻璃球），一句抒情都没有。
- 情绪转折全靠主歌末句"那些我以为 散不掉的 都留在昨天"做承接。
- 桥段用身高线做载体："一米二 一米四 最后一道停在我再也长不上去的地方"，把"长大"这个抽象概念量化成刻度。
- 副歌"楼高了把天空切成一块一块"用空间变化代替时间流逝，避开了怀旧歌的陈词。

**可复用结构**：白描堆物 → 一句承接 → 副歌写变化 → 桥段写一个能测量的物件 → 末句收在感官上。

**已知修订**

- 初稿"知了"→ 现用"蝉"。成因是读音级：字认得、词也认得，但"了"读 le 时拼音空间几乎独占，读 liǎo 时 24 个同音字分摊，模型取最高频。蝉 chán 单音、一级字，还顺手接上了全曲的 an 韵。
- **押韵审计发现初稿副歌根本不押**：偶数行韵脚是 我(波) / 方(唐) / 跑(豪)，三段跑韵。已按对句押韵重排为 样(唐) / 方(唐) / 望(唐)，只改三个落点句，意象未动（"追着我跑"→"在巷口张望"）。
- 定稿韵脚列：主歌 面/年/线/天（全 an 韵），副歌 样/方/望，桥段 墙/方/光，末段 慢/班。
- 结果：8 段对句押韵全部成立，高风险 0 项。
- 教训：**押韵不是写完再调的东西**。像"那些我以为 散不掉的日子啊"这类以语气词收尾的句子，韵是悬空的，改成"都留在昨天"才落地。

同批替换（同一次生成暴露的其他少数派读音）：

| 初稿 | 定稿 | 原因 |
|---|---|---|
| 攥着两毛钱 | 捏着两毛钱 | zuàn 全汉语仅 3 字，无同音邻居，必错 |
| 弹珠滚进阴沟 | 小珠子滚进阴沟 | 弹读 dàn 是少数派，多数读 tán |
| 长大不是 / 长成大人 | 成年不是 / 变成大人 | 长读 zhǎng 是少数派，多数读 cháng |
| 一样一样还给时光 | 一样一样退回时光 | 还读 huán 是少数派，多数读 hái |
| 像风筝的线 | 像一根长线 | 筝是低频字；虽 zhēng 有 79 个同音字、听感不致歪，顺手换掉 |

**复用此段时勿改回知了、攥着、弹珠、长大、还给。**

## 二、《钥匙串上的老家》（民谣叙事，4 分钟）

**同族但换了视角**：不写童年，写离乡成年人。证明同一套结构能承载不同题材。

**关键技法**

- 全曲的物理锚点只有一个：钥匙串上的老家钥匙。"那把钥匙我一直没舍得换"。
- Pre-Chorus 用一句判断句制造反转："那种好，是一个老人对另一个城市的客气"——把父母的体谅写成一种礼貌的疏离。
- 桥段用"她忘了这些口味我早就变了很多"制造愧疚，不写"我对不起他们"。
- 末句"就当 他们看见了"用动作留白收尾。

## 三、《你那边几点》（都市夜 R&B，3.5 分钟）

**钩子**："你那边几点"——一句日常问句当标题和记忆点。

**关键技法**

- 全曲在跟不在场的人说话，第二人称贯穿，从未交代对方身份。
- 主歌近乎不押韵，靠口语流动；押韵只在副歌出现，形成听觉切换。
- 最重的情感放在桥段，且用"其实"开头："其实我想说的不是晚安，是你能不能别那么远"，然后立刻退回"早点睡"。
- 副歌用"我这句轻得像风／你却是我一整夜的重"做轻重对比，两句完成全曲论点。

## 四、《饲养指南》（寓言式华语流行，4 分钟）

**钩子**：动物比喻系统——"把尖牙藏进吻你的角度"。

**已知修订**：初稿用"獠牙"，实生成时"獠"被读成 luǒ。獠是 GB2312 二级罕用字，无拼音层的模型会把它映射到高频邻居。已改为"尖牙"，字数不变，旋律无需调整。**复用此句时勿改回獠牙。**

同段 Pre-Chorus 的"一声低吠"被唱成"低垂"。吠是一级常用字，问题不在字形而在搭配：低吠不在常用词表（低垂 163 次、低声 3202 次），模型按语言先验把非常用搭配补成了高频词。改为"一声犬吠"（词表内固定搭配）或"一声低吼"。**结论：低频字看字形，低频搭配看搭配——两层要分别检查。**

**关键技法**

- 一套比喻贯穿到底：笼子、饲养员、牙齿、爪子、玻璃、标签、品种、低吠。中途不换系统。
- 副歌四句一组全押韵，长句推进（"谁先动了真心谁就先被驯服"），工整度本身构成风格。
- 桥段自我拆穿："他们说这叫成熟，我说这叫圈养成功"，把全曲的比喻系统一句话戳破。
- 末段升调后反转："我本想做一次优雅的猎手，结果跪下来求你 别走"——从捕食者跌回被驯者，完成概念闭环。

## 质量底线（四篇共同点）

1. 每首只有一个记忆点，且是日常语言。
2. 抽象概念一律换成可测量、可触摸的东西（刻度、钥匙、未读格、獠牙角度）。
3. 最高情绪点放在桥段，副歌负责反复，不负责爆发（寓言式除外）。
4. 末句不解释、不总结，收在动作或感官上。
